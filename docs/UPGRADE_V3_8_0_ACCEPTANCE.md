## 本轮兼容调整

- 复用3.8的书库权限接口verifyAccess和verifyAccessLevel，传入完整用户主体，保留API密钥的书库范围约束。小说下载、任务、验重与上传均已调整。
- 自定义上传音频时长读取复用官方probeAudioFile。扫描合并保留TXT/EPUB同书附件与自写入保护，并接入上游有界并发管线。
- 保留生产已执行133项迁移的文件和SHA256，通过Drizzle生成0133_upstream_v3_8_custom。新增内容与官方两项迁移的SQL语句集合一致，实际追加一项账本记录。PG18的133到134迁移待隔离运行。
- 3.8新增146项简体中文文案，API密钥与TorBox等页面沿用国际化。
- DjVu队列容量测试的计时与队列到期测试分开，立即收集并发Promise结果，避免整套并行回归时200毫秒队列期限影响容量断言。生产DjVu实现未改动。
