# 定制功能状态矩阵

状态表示当前仓库可确认的实现进度。代码进入分支、单元测试通过、开发环境构建成功和群晖端到端验证是不同阶段，不可互相替代。

| 功能 | 状态 | 完成标准 |
| --- | --- | --- |
| v3.5.0 定制分支 | 已建立 | `custom/bookorbit-v3.5.0` 的祖先为官方 `v3.5.0` tag |
| TXT 上传 | 代码已迁移，待验证 | 网页可上传 UTF-8/GBK 等 TXT，文件保存和元数据处理成功，且不自动转 EPUB |
| TXT 扫描 | 代码已迁移，待验证 | 扫描到 TXT，断点/重复扫描安全；TXT 与同书 EPUB 归并到同一书籍记录 |
| TXT 元数据提取 | 代码已迁移，待验证 | 常见编码和文件名可正确处理，失败不阻断入库 |
| 手动 TXT 转 EPUB | 代码已迁移，待验证 | 详情页可设置编码和章节策略并触发转换；保留原 TXT；不意外覆盖 EPUB |
| TXT/EPUB 共享元数据 | 代码已迁移，待验证 | 书名、作者、封面、编辑和下载格式选择在两种文件间一致 |
| 自动刮削设置 | 部分代码已迁移，流程待验证 | 上传和扫描能按设置进入可观测队列；失败可重试；不会覆盖更可信的现有字段 |
| 豆瓣元数据 | 代码已迁移，真实来源待验证 | 搜索、详情匹配、字段映射、封面来源和异常处理均有测试与界面验证 |
| 番茄元数据 | 代码已迁移，真实来源待验证 | 明确区分元数据搜索与正文下载，并对来源响应变化安全失败 |
| 百度百科、七猫、起点 | 未实现 | 逐个确认公开可用性、字段质量和访问条款后再实现 |
| 封面显示和远程图片策略 | 未解决 | 外链、缓存、请求失败和占位图行为一致；不存在无上限缓存 |
| 书源检索与正文下载 | 未实现 | 至少一个合法来源完成搜索、下载、书籍元数据/封面写入、去重、入库及重试验证 |
| Project Gutenberg 插件 | 草稿 | 目前有独立草稿和测试文件，尚未证明被 BookOrbit 插件运行时发现或完成下载入库 |
| 漫画书源 | 未实现 | 合法来源完成搜索、下载、元数据、封面和去重入库验证 |
| 有声书/M4A | 需要验证 | 扫描/上传、文件关联、播放、时长、章节和内嵌标签在目标平台通过验证 |
| 新增界面中文翻译 | 部分完成 | 新增和修改界面无遗漏的可见英文文案，中文翻译通过 locale 检查 |
