## 番茄下载代码接入

已增加 `BookSourceModule`：

- `GET /api/v1/book-sources/status` 返回是否配置下载器，不返回可执行文件路径或凭据。
- `POST /api/v1/libraries/:id/sources/fanqie` 接受 `{ bookId: string, folderId?: number }`，立即返回 HTTP 202 和 `BookSourceJob`。要求上传和直接下载权限，提交、执行及入库前检查目标书库权限。
- “书源搜索与下载”增加“小说书源”页签。番茄搜索复用元数据搜索接口，下载按钮取来源数字 ID，选择有编辑权限的电子书库。
- 下载任务保存到 PostgreSQL，关闭网页不取消任务。排队任务在服务重启后继续领取；正在下载的任务若租约失效会标记失败，可手动重试，不承诺章节断点续传。
- `GET /api/v1/book-sources/jobs?cursor=<id>` 每页最多 25 条；`GET /api/v1/book-sources/jobs/:id` 查询详情；`POST /api/v1/book-sources/jobs/:id/cancel` 取消；`POST /api/v1/book-sources/jobs/:id/retry` 重试。所有查询及操作限制为当前用户自己的任务。
- 状态包括排队、下载与校验、入库、完成、失败、取消。当前显示阶段进度，不提供未经上游确认的章节百分比。页面每 3 秒刷新当前页。
- 数据库事务锁协调应用实例，全局串行执行，每位用户最多 20 个未完成任务。领取后每 2 秒续租，租约 60 秒。实例异常退出后，不会把旧实例迟到的结果写入新租约。
- 取消下载通过数据库标记传递，最长等待一个正常轮询周期；入库开始后拒绝取消。入库中断或结果未确认时禁止直接重试，避免重复写入。
- 单次下载生成认证口令和仅绑定 loopback 的子进程；不开放新宿主端口，不新增部署服务。Node 监管进程检测父进程退出并终止下载器，下载器有独立最长生存时间。正常结束立即清理暂存目录；异常退出遗留的目录超过两小时后由定期清理回收，每轮最多扫描 1000 项，不跟随符号链接。
- 固定上游下载器 v2.4.15 的 Linux musl amd64/arm64 SHA-256。拒绝缺章、失败任务、超大文件及结构损坏的 EPUB，再经已有上传服务入库。使用上游预览书名命名文件；具体保存目录由选定书库组织模式和上传命名规则控制，未硬编码 `/volume1/library/ebook`。
- 同用户、同目标书库、同番茄来源 ID 的有效下载或入库记录只保留一个。已有目标文件仍由上传逻辑拒绝覆盖；已完成记录对应的书籍被删除后允许重新下载。无法为早期通过普通扫描导入、没有来源记录的文件推断来源身份。
- EPUB 内嵌的元数据与封面随文件保留。尚未验证上游每本书均输出封面，不能承诺每本下载都有图片。

### 可复现运行材料

```sh
node scripts/book-source/install-tomato-runtime.mjs --directory /path/to/tomato-runtime --arch amd64
# 离线材料可追加 --source /path/to/downloaded/binary
```

把生成目录只读挂载到现有 BookOrbit 容器，例如 `/opt/bookorbit-tomato`，在同一应用配置：

```dotenv
TOMATO_DOWNLOADER_PATH=/opt/bookorbit-tomato/downloader
BOOK_SOURCE_DOWNLOAD_TIMEOUT_MS=600000
```

无需映射下载器端口。默认镜像不打入该二进制。上游声明及运行材料说明位于 `licenses/tomato-novel-downloader-NOTICE.md`。
