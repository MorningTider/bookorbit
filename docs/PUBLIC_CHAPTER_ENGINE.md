# 公开章节下载与TXT转EPUB

2026-10-25已部署生产r8，生产健康与公网入口检查通过。原番茄下载与直接文件书源继续保留。

## 使用入口

“书源搜索与下载”的“小说书源”页签支持番茄及起点公开免费卷。起点先在元数据提供商中启用，可搜索后提交“下载免费章节选集”。生成书名明确附加“公开免费章节选集”，目录和简介标明选集范围，不冒充完整作品。

拥有manage_book_requests权限的用户可展开“管理公开章节书源”，粘贴或选择JSON文件导入。普通下载用户只能选择管理员已配置的来源和输入来源书籍编号，不可提交任意URL或脚本。提交仍要求library_upload及book_request_self_fulfill，并验证目标书库editor权限。管理员并不因管理规则自动获得下载权限。

模板见examples/public-chapter-sources.example.json。example.org只是演示结构，不是可用书源，需替换为已确认可保存的实际来源。首版是BookOrbit自定义声明式CSS格式，不是完整Legado兼容层，不执行JavaScript、正则提取脚本或任意请求代码。

## 规则格式

sources最多20项。key为1到7位小写字母/数字/连字符且首位字母，不能使用内置fanqie/qidian。origin为固定HTTPS公开站点；bookPath、catalogPath各包含一次{id}，不允许跳到其他站点。书籍编号为1到16位字母/数字/下划线/连字符。

titleSelector、authorSelector从作品页读取元数据。chapterLinkSelector从完整目录选择章节链接；chapterPublicSelector须明确匹配公开链接自身或其后代，chapterRestrictedSelector匹配受限链接。未确认访问状态即失败，不猜测免费。章节标题取链接文字，须与chapterHeadingSelector匹配。正文页须存在publicPageSelector且不存在restrictedPageSelector，contentSelector内读取p段落，排除脚本、样式、导航等。

本版只读取单页完整目录，不自动追踪分页；规则维护者须确认所选页面含完整目标目录。不支持把未知分页、截断预览或缺少权限标志的站点当作可用来源。源站缺少可稳定确认的完整正文标记时，不应启用该规则。

## 网络、任务与持久化

固定来源HTTPS、DNS地址检查和绑定；禁止重定向、外站链接及私网目标。单响应2MiB，单章10万字符，总正文与EPUB各64MiB，上限1000章。全局沿用原后台队列串行执行，相邻章节至少间隔1秒，整个任务受原下载超时限制，关闭页面后继续运行，取消/重试/权限复查及入库幂等沿用既有流程。任一已选择章节失败即拒绝整份文件，不保存缺章成功结果；阶段进度沿用当前任务状态，尚无逐章百分比。

规则文件在应用数据目录public-chapter-sources.json，身份历史在同名.identities文件，需随应用配置一并备份。原有标识不能用于不同规则，包括先删后建；更改规则需新标识，避免排队任务意外换来源。规则文件用0600临时文件原子替换，保留最多200个历史身份。删除的来源不能启动或重试旧任务；已执行任务持有当次规则，仍可在任务列表取消。

新增接口：

- GET/PUT /api/v1/book-sources/chapter-rules：管理员读取/替换规则，PUT为{sources:[...]}。
- GET /api/v1/book-sources/chapter-sources：下载权限用户读取key/label列表。
- POST /api/v1/libraries/:id/sources/chapters：{source,bookId,folderId?}，返回202与持久任务。
- POST /api/v1/libraries/:id/sources/qidian：{bookId,folderId?}，返回202与持久任务。

无需数据库schema变更。既有source_book_id字段使用来源前缀隔离，最长24字符，避免与番茄的纯数字编号冲突。来源规则管理、下载、历史任务读写分别经过后端权限检查，任务按当前用户隔离。

## 起点与七猫

起点只选结构化目录vS=0的公开卷；逐章检查bookId/chapterId/标题、vipStatus=0、limitFree=0、正文段落和长度。目录免费标签不能作为判断依据。真实样本目录取得130章公开卷，排除1288章VIP卷；群晖隔离实例已完成130章下载和入库，生成714111字节EPUB，导航目录130章，简介标明排除1288章。浏览器搜索、提交及重复任务返回通过；生产未写入验收书籍。

七猫仍只有元数据能力，未找到稳定且经核验的公开章节下载路径；TaleBook对应适配仅为元数据，没有直接可复制的正文下载实现。不展示不可用下载按钮，不拷贝未核验签名或App解密逻辑。

## TXT转换完善

继续支持自动/UTF-8/GB18030/UTF-16 LE/BE编码及自动/中文/英文/单章策略；新增无空格中文章名识别、空白和纯标题拒绝、显式UTF-8损坏与UTF-16截断检查、单行1MiB上限、XML控制字符清理、内部取消信号及临时数据清理。EPUB保留作者、简介、出版社、日期、ISBN及可用封面；无ISBN时生成唯一UUID，避免同名TXT共用文件名作为标识。输出不覆盖原EPUB，同书格式关联沿用原入库转换流程。

章节引擎使用内部随机标记分章，正文中的“Chapter 2”等句子不会变成额外目录。群晖隔离实例已验证同书TXT/EPUB关联、错误编码拒绝后正确编码重试及禁止覆盖。转换前和关联前均要求书库editor权限。

## TXT直接网页阅读（隔离候选）

用户确认同时支持TXT、EPUB及已有主流格式。TXT打开时通过已有带认证的EPUB资源接口生成临时阅读投影，不修改原TXT、不向book_files增加EPUB。缓存位于容器/tmp/bookorbit-txt-reader，目录0700、文件0600，不需要备份。正式“转换为EPUB”仍是独立、显式的永久格式添加操作。

读取首先验证书库访问和fileId归属，缓存键包含文件ID、路径、大小和修改/变更时间。源文件上限128MiB，流式解析，生成时源文件变化即拒绝结果。一次准备一本，同一文件并发请求合并，准备120秒超时；前端首次TXT等待上限150秒。缓存256MiB、16文件，预留128MiB生成空间，近期十分钟内访问的缓存受保护，空间不足返回503而不清除近期阅读资源。实际可驻留数量取决于大小和预留空间，不能把配置容量等同于可同时装满的图书数量。临时文件失败后清理。

无章节的大段文本按十万UTF-16代码单元上限拆分，不截断代理对；沿用原章节识别和编码逻辑。UTF-8、GB18030/GBK、带BOM的UTF-16使用自动识别；不支持把加密或任意二进制文件当作TXT。原转换的目录策略不受此阅读专用切分选项影响。阅读位置继续绑定原TXT文件ID，缓存重建时章节结构确定；不把TXT投影CFI直接同步到另一格式的EPUB。
