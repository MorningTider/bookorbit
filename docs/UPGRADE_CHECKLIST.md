# BookOrbit 上游升级检查清单

每次把官方新 tag 合入定制分支时使用。完成状态要附命令、测试结果或部署日志，不能只勾选而没有证据。

## 上游版本与工作区

- [ ] 从官方仓库确认新正式 tag、提交哈希和发布日期。
- [ ] `git fetch upstream --tags` 后确认 tag 指向与官方发布一致。
- [ ] 确认当前工作区干净，定制分支和升级分支名称正确。
- [ ] 创建升级分支，只合并正式 tag，不混入上游未发布分支提交。
- [ ] 检查合并提交和冲突，记录每个定制补丁是否仍然需要。
- [ ] 更新 `CUSTOM_BRANCH_WORKFLOW.md`、需求清单和功能矩阵中的基线版本。

## 源码和依赖

- [ ] 检查 `AGENTS.md`、README、开发文档、迁移指南及上游 breaking changes。
- [ ] 按该 tag 要求安装准确 Node、pnpm 版本和依赖，确认使用锁文件的 frozen install。
- [ ] 构建 `packages/types`、`packages/plugin-api` 和所有共享包，再执行全量类型检查。
- [ ] 检查 TXT 上传、扫描、元数据提取、转换、TXT/EPUB 归并和格式选择 API。
- [ ] 检查豆瓣、番茄和后续中文提供商接口变化、字段权限、封面 URL、超时和限流处理。
- [ ] 检查自动刮削队列的并发上限、进度、失败日志、重试和幂等行为。
- [ ] 检查插件 API、插件装载位置、插件配置、来源合法性和下载后入库流程。
- [ ] 检查新增或修改的中英文 locale、格式校验、权限检查和多用户隔离。
- [ ] 确认 `node_modules`、`.pnpm-store`、构建产物、`.env` 和本地测试数据没有进入提交。

## 数据库和验证

- [ ] 对照上游数据库 schema 变更；按项目 Drizzle 流程生成迁移，不手写 SQL。
- [ ] 在临时数据库运行迁移、回滚演练和目标版本测试。
- [ ] 运行相关单元测试、前后端类型检查、lint、格式检查和生产构建。
- [ ] 测试大书库分页、批处理和扫描性能，确认无全库载入、无 N+1 查询、并发有界。
- [ ] 端到端验证 TXT 上传、扫描、手动转换、格式共享元数据和 EPUB 客户端读取。
- [ ] 端到端验证自动元数据获取、失败重试、封面显示和有声书/M4A 入库。
- [ ] 书源检索和下载只对已确认合法的来源测试，并分别记录搜索、实际文件获取和入库结果。
- [ ] 在目标群晖隔离环境验证启动、重启、健康端点、日志、权限和升级恢复。

## 镜像、SPK 和群晖

- [ ] 构建并固定版本号的 BookOrbit 镜像或 SPK，记录摘要、依赖版本和构建来源。
- [ ] 如果使用 SPK，检查包结构、脚本权限、架构、DSM 兼容性及停止/启动/升级/卸载行为。
- [ ] 检查 Docker Compose 的 `APP_IMAGE`、端口、时区、持久化目录和书库挂载。
- [ ] 确认 PostgreSQL 主版本和 pgvector 版本；未经验证不从 PostgreSQL 18 切换到 17 或反向复用数据目录。
- [ ] 备份数据库、BookOrbit 配置和书库；确认备份恢复步骤可执行。
- [ ] 用独立端口、数据库、应用数据目录和测试书库完成隔离安装。
- [ ] 查看应用和数据库日志，确认健康检查正常且没有静默启动失败。
- [ ] 完成验收后再切换生产服务，并记录切换时间和回滚镜像/SPK。
- [ ] 发生失败时恢复旧版本和匹配的数据备份，记录问题后停止生产切换。

## 收尾记录

- [ ] 更新 `CUSTOMIZATION_REQUIREMENTS.md` 的实现状态和未完成项。
- [ ] 更新 `CUSTOM_FEATURE_MATRIX.md`，只把实际验证通过的功能标记为完成。
- [ ] 更新群晖部署文档中的已验证镜像、数据库、目录、端口和日志位置，不写密码或令牌。
- [ ] 保存测试输出、构建摘要和隔离环境验收结果，排除用户文件、凭据和隐私数据。
